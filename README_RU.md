# Quick Node Creator для XenForo 2

[![XenForo Version](https://img.shields.io/badge/XenForo-2.2%20%7C%202.3-blue.svg)](https://xenforo.com)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](https://opensource.org/licenses/MIT)

**[English version](README.md)**

**Quick Node Creator** — это плагин для XenForo 2, который позволяет создавать, редактировать и удалять разделы и категории прямо со страниц форума, без необходимости заходить в панель администратора. 

Дополнение решает задачу делегирования прав: вы можете назначить кураторов или модераторов, которые будут управлять структурой своих разделов автономно.

## Возможности

* **Управление узлами с форума:** Создание, изменение и удаление разделов, категорий и узлов-ссылок через стандартный интерфейс XenForo.
* **Шаблоны прав:** Администраторы могут заранее создавать готовые наборы прав (например, "Закрытый раздел", "Только для чтения"), которые кураторы смогут применять к своим разделам в один клик.
* **Локальные и глобальные права:** Нативная интеграция с системой прав XenForo. Права на управление структурой можно выдать на весь форум или ограничить конкретным родительским разделом.
* **Модерация удалений:** При удалении раздела модератором он не стирается из базы данных, а скрывается со статусом «Ожидает удаления». Главный администратор может подтвердить или отменить удаление через логи в панели управления.
* **Создание приватных разделов:** Галочка при создании узла автоматически настраивает права доступа так, чтобы раздел был виден только его автору и назначенным администраторам.
* **Защита системных групп:** Настройки плагина блокируют кураторам возможность выдавать права на раздел администраторам или другим защищенным группам (настраивается в АЦП).
* **Логирование и откат изменений:** Все действия кураторов записываются. В панели администратора можно просмотреть изменения (с удобным и понятным переводом прав) и откатить их в один клик с полным восстановлением настроек узла.

## Установка
1. Скачайте `.zip` архив из раздела [Releases](../../releases).
2. Загрузите содержимое папки `upload` в корень вашего форума.
3. Перейдите в **Плагины** в панели администратора XenForo.
4. Установите **[VolkDev] Quick Node Creator**.

## Настройка
1. Перейдите в **Права доступа -> Права групп пользователей** или в права узла.
2. В блоке **Quick Node Creator** выдайте нужные права:
   * *Может создавать узлы из фронтенда*
   * *Может редактировать узлы из фронтенда*
   * *Может удалять узлы из фронтенда*
   * *Может управлять правами групп из фронтенда*
3. В настройках **Настройки -> Quick Node Creator** укажите группы, которые могут видеть приватные разделы в обход правил.
