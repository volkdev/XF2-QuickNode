# [VolkDev] Quick Node Creator – Плагин XenForo 2 для управления разделами из фронтенда 🚀

**[🇺🇸 English version (Английская версия)](README.md)**

**[VolkDev] Quick Node Creator** — это крупный, мощный и продуманный до мелочей **плагин (add-on) для XenForo 2**, который переносит сложный процесс управления узлами (создание разделов и категорий) из админ-панели (ACP) прямо в публичную часть форума (фронтенд). 

Идеальное решение для масштабных проектов: игровых порталов, региональных сообществ, roleplay серверов или площадок с гильдиями. Плагин позволяет безопасно делегировать управление структурой форума кураторам и лидерам, **не выдавая им доступ к панели администратора**.

---

## 🚀 Почему стоит выбрать Quick Node Creator?
Плагин написан со строгим соблюдением стандартов XenForo (MVC, Entities, Services), не использует "грязных" хаков, абсолютно безопасен от SQL-инъекций и готов к работе на высоких нагрузках. Он позволяет разгрузить главных администраторов и дать автономность локальным модераторам.

## ✨ Ключевые возможности

### 🛠️ Полное управление разделами из фронтенда
- **Интуитивный интерфейс**: Кураторы с правами могут создавать, редактировать и удалять разделы, категории и разделы-ссылки прямо со страницы форума.
- **Нативные модальные окна**: Использование стандартных AJAX-окон XenForo для максимального удобства.

### 🔐 Глубокая интеграция с правами XenForo
- **Глобальные и локальные права**: Использует нативную систему прав XF. Вы можете выдать права на создание узлов глобально на весь форум или локально — только для определенных категорий (например, лидеру фракции в его разделе).

### 🛡️ Безопасное удаление (Система подтверждений / Approvals)
- **Защита от вандализма**: Удаление раздела модератором не стирает его из базы данных.
- **Модерация удаления**: Раздел скрывается и помечается как «Ожидает удаления». Главный администратор в ACP может одобрить удаление или отклонить его, мгновенно вернув раздел на место вместе со всем содержимым.

### 👁️ Приватные разделы в один клик
- **Легкая настройка доступов**: Возможность создавать закрытые узлы галочкой при создании.
- **Автоматизация `viewNode`**: Плагин сам безопасно перестроит сложные права XenForo, оставив раздел видимым только его создателю и системным группам-исключениям (например, Администраторам).

### 📋 Мощная система логов и откатов (Revert)
- **Тотальный контроль**: Каждое действие куратора (создание, изменение настроек, редактирование прав) скрупулезно логируется.
- **Откат в один клик**: Администратор видит старое и новое состояние раздела (до/после) и может **откатить любое действие** прямо из админки, мгновенно восстановив все настройки и права!

### 🚫 Защита важных групп
- **Изоляция привилегий**: Настройка `qnc_protected` для групп не позволит даже самым продвинутым фронтенд-кураторам выдать админские или супер-модераторские права случайным пользователям форума.

### ⚡ Полная совместимость с XenForo 2.3
- Код написан с использованием обновленных AJAX-обработчиков XenForo, что делает плагин на 100% совместимым с новой архитектурой ванильного JavaScript в XF 2.3.

## 📥 Инструкция по установке
1. Скачайте `.zip` архив последней версии из раздела [Releases](../../releases).
2. Распакуйте содержимое папки `upload` в корневую директорию вашего форума на хостинге.
3. Перейдите в Панель администратора XenForo -> **Плагины**.
4. Нажмите Установить напротив плагина **[VolkDev] Quick Node Creator**.

## ⚙️ Настройка прав
1. Перейдите в **Права доступа -> Права групп пользователей** (или в права конкретного узла).
2. В блоке **Quick Node Creator** выдайте нужные права кураторам:
   * *Может создавать узлы из фронтенда*
   * *Может редактировать узлы из фронтенда*
   * *Может удалять узлы из фронтенда*
   * *Может управлять правами групп из фронтенда*
3. В настройках **Настройки -> Quick Node Creator** укажите административные группы, которые всегда должны видеть закрытые (приватные) разделы.
