# [VolkDev] Quick Node Creator 🚀

[![XenForo Version](https://img.shields.io/badge/XenForo-2.2%20%7C%202.3-blue)](https://xenforo.com)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](https://opensource.org/licenses/MIT)

**[🇺🇸 English version (Английская версия)](README.md)**

**Quick Node Creator** — это мощный плагин для XenForo 2, который позволяет вашим модераторам управлять деревом узлов (разделов) прямо с пользовательской части форума, без доступа к панели администратора (ACP).

Идеальное решение для крупных проектов (например, игровых или региональных форумов), где есть кураторы категорий, которым нужно дать власть управлять разделами, не выдавая админку.

## ✨ Возможности
* **Управление из фронтенда:** Модераторы с правами могут создавать, редактировать и удалять подразделы прямо со страницы категории/форума.
* **Гибкая система прав:** Полная интеграция с нативной системой прав XenForo. Вы можете выдавать права на создание/редактирование разделов глобально или только для конкретных родительских узлов.
* **Безопасное удаление (Аппрувы):** Для защиты от вандализма удаление раздела из фронтенда не удаляет его физически. Раздел скрывается и получает статус "Ожидает удаления". Полное удаление подтверждает администратор в логах.
* **Приватные разделы:** Возможность в один клик создавать закрытые (приватные) узлы, которые видны только создателю и разрешенным группам.
* **Локальные модераторы:** Назначение пользователей локальными модераторами узла прямо из пользовательской части.
* **Мощная система логов и откатов (Revert):** Любое действие (создание, изменение настроек, изменение прав доступа) логируется в ACP. Администратор видит старое и новое состояние раздела и может **откатить действие в один клик**!
* **Защита важных групп:** Опция `qnc_protected` для групп не позволит модераторам случайно или намеренно выдать админские права себе или кому-то еще.

## 📥 Установка
1. Скачайте `.zip` архив последней версии из раздела [Releases](../../releases).
2. Распакуйте содержимое папки `upload` в корневую директорию вашего форума.
3. Перейдите в Панель администратора -> **Плагины**.
4. Нажмите Установить напротив **[VolkDev] Quick Node Creator**.

## ⚙️ Настройка
1. Перейдите в **Права доступа -> Права групп пользователей** (или права узлов).
2. В блоке **Quick Node Creator** выдайте нужные права кураторам:
   * *Can create nodes from the front-end*
   * *Can edit nodes from the front-end*
   * *Can delete nodes from the front-end*
   * *Can manage group permissions from the front-end*
3. В настройках **Настройки -> Quick Node Creator** можно указать группы, которые всегда видят приватные разделы.
