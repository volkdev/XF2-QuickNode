# [VolkDev] Quick Node Creator 🚀

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](https://opensource.org/licenses/MIT)

**[🇺🇸 English version (Английская версия)](README.md)**

**Quick Node Creator** — это крупный, мощный и продуманный до мелочей плагин для XenForo 2. Он переносит сложный процесс управления узлами (разделами и категориями) из админки прямо во фронтенд форума. 

Плагин идеально подходит для масштабных проектов (например, игровых порталов, региональных сообществ или площадок с гильдиями), где необходимо делегировать управление структурой форума кураторам, **не выдавая им при этом доступ к панели администратора (ACP)**.

Плагин написан со строгим соблюдением стандартов XenForo (MVC, Entities, Services), не использует грязных хаков, безопасен от инъекций и готов к работе на высоких нагрузках.

## ✨ Ключевые возможности
* **Полное управление из фронтенда:** Кураторы с правами могут интуитивно создавать, редактировать и удалять разделы, категории и разделы-ссылки прямо со страницы форума.
* **Глубокая интеграция с правами XenForo:** Использует нативную систему прав. Вы можете выдать права на создание узлов глобально на весь форум или локально только для определенных категорий.
* **Безопасное удаление (Система Аппрувов):** Встроенная защита от вандализма. Удаление раздела модератором не стирает его из БД. Раздел скрывается, помечается как «Ожидает удаления», а администратор в ACP может одобрить удаление или отклонить его, вернув раздел на место.
* **Приватные разделы в один клик:** Возможность создавать закрытые узлы галочкой при создании. Плагин сам безопасно перестроит права `viewNode`, оставив раздел видимым только создателю и группам-исключениям (админам).
* **Мощная система логов и откатов (Revert):** Каждое действие (создание, изменение настроек, изменение прав) скрупулезно логируется. Администратор видит старое и новое состояние раздела и может **откатить любое действие в один клик**, мгновенно вернув все настройки и права!
* **Защита важных групп:** Настройка `qnc_protected` для групп не позволит даже самым привилегированным фронтенд-кураторам выдать админские или супер-модераторские права кому попало.
* **Совместимость с XenForo 2.3:** Код написан с использованием стандартных AJAX-обработчиков XenForo, что делает его полностью совместимым с новой архитектурой ванильного JavaScript в XF 2.3.

## 📥 Установка
1. Скачайте `.zip` архив последней версии из раздела [Releases](../../releases).
2. Распакуйте содержимое папки `upload` в корневую директорию вашего форума.
3. Перейдите в Панель администратора -> **Плагины**.
4. Нажмите Установить напротив **[VolkDev] Quick Node Creator**.

## ⚙️ Настройка
1. Перейдите в **Права доступа -> Права групп пользователей** (или в права конкретного узла).
2. В блоке **Quick Node Creator** выдайте нужные права кураторам:
   * *Может создавать узлы из фронтенда*
   * *Может редактировать узлы из фронтенда*
   * *Может удалять узлы из фронтенда*
   * *Может управлять правами групп из фронтенда*
3. В настройках **Настройки -> Quick Node Creator** укажите административные группы, которые всегда должны видеть приватные разделы.
